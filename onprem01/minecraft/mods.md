# Fabric server mods

Java edition only, reached over the mesh at `mc.example.com:25565`. Whitelist on.

| Purpose | Mods |
|---|---|
| Server performance | Lithium, FerriteCore, Krypton, C2ME, ScalableLux, ModernFix, Very Many Players, Noisium, ThreadTweak, Alternate Current, Structure Layout Optimizer |
| Profiling | Spark |
| World pre-generation | Chunky |
| Technical play | Carpet (+ addons), Servux, Syncmatica |
| Map | BlueMap |
| Admin | Ledger (block logging / rollback), LuckPerms |
| Quality of life | Universal Graves, Styled Chat, TreeTimber |

Pre-generate the world with Chunky before anyone plays, then let BlueMap
render it overnight. Filter Modrinth by the exact game version; one
incompatible jar stops the server booting.
